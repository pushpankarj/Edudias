# EduDias 🎓

> An accessible, zero-cost self-study web platform designed for CBSE and ICSE students (Classes 6–10).

EduDias simplifies middle and high school learning by providing interactive study notes, engaging educational logic games, test series, and a collaborative doubt-solving forum—all built on lightweight, serverless web architecture.

---

## ✨ Features

- **Interactive Study Notes:** Comprehensive, easy-to-read content formatted for rapid revision across CBSE and ICSE curricula.
- **Logic & Learning Games:** Engaging web-based educational activities that reinforce core concepts.
- **Peer Doubt-Solving Forum:** Real-time discussion board powered by Firebase, allowing students to ask questions and share solutions.
- **Lightweight & Serverless:** Built to run directly in the browser with zero server latency and minimal resource overhead.

---

## 🛠️ Tech Stack

- **Frontend:** Custom HTML5, CSS3, JavaScript (ES6+)
- **Backend / Database:** Firebase Realtime Database
- **Hosting / Infrastructure:** Serverless Client-Side Web Architecture
